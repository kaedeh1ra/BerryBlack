# WB Select

Учебный прототип премиальной витрины. Не является официальным сайтом Wildberries.

## Возможности

- Адаптивный каталог и фильтры категорий.
- Избранное и демо-корзина с сохранением в localStorage.
- Подборка редакции и описание концепции сервиса.

Товары, бренды и цены демонстрационные. Реальная оплата и оформление заказов отсутствуют. Фотографии загружаются с Unsplash и требуют доступа к интернету.

## Запуск

Откройте `dist/index.html` в браузере или запустите из корня проекта:

```sh
python3 -m http.server 4173 --directory dist
```

Затем откройте http://localhost:4173.

## Структура

`dist/index.html` — разметка, `dist/css/style.css` — стили, `dist/js/data.js` — демо-данные, `dist/js/app.js` — логика. Сборка не требуется.

## GitHub Pages

В репозитории есть `.github/workflows/pages.yml`: каждый push в `main` публикует папку `dist`. Один раз включите в GitHub: Settings → Pages → Source: **GitHub Actions**.
